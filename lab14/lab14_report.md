- семафоры;

# Задание 1. Реализация механизма семафоров

## Постановка задачи

Требуется реализовать shell-скрипт, обеспечивающий блокировку ресурса при обращении нескольких процессов.

## Код программы

```bash
#!/bin/bash

LOCKFILE="/tmp/resource.lock"

while true
do
    if [ -f "$LOCKFILE" ]; then
        echo "Ресурс занят другим процессом"
        sleep 2
    else
        touch "$LOCKFILE"
        echo "Ресурс захвачен"
        sleep 5
        rm -f "$LOCKFILE"
        echo "Ресурс освобожден"
        break
    fi
done
```

## Принцип работы

Сценарий проверяет наличие lock-файла.
Если файл существует — ресурс считается занятым.
Если файл отсутствует — процесс создаёт lock-файл и получает доступ к ресурсу.

## Результаты выполнения

При запуске нескольких процессов одновременно только один процесс получает доступ к ресурсу. Остальные процессы переходят в режим ожидания.

## Код программы

```bash
#!/bin/bash

FILE="/usr/share/man/man1/$1.1.gz"

if [ -f "$FILE" ]; then
    less "$FILE"
else
    echo "Справка для команды отсутствует"
fi
```

## Анализ работы программы

Сценарий проверяет существование файла справки. При наличии файла выполняется его открытие через less.

## Особенности реализации

# Задание 3. Генерация случайной последовательности

## Код программы

```bash
#!/bin/bash

for ((i=0; i<20; i++))
do
    CHAR=$((RANDOM % 26 + 65))
    printf "\$(printf '%03o' $CHAR)"
done

echo
```

## Объяснение работы

Случайное число преобразуется в ASCII-код латинской буквы.
