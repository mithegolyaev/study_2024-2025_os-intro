## Введение
Emacs является одним из самых известных и функциональных текстовых редакторов в мире UNIX/Linux. Он применяется для написания программного кода, подготовки документов, работы с командной строкой, почтой и множеством других задач. Гибкость редактора обеспечивается встроенным языком расширений Emacs Lisp.

## Теоретические сведения
### Основные понятия
- **Буфер** — объект, содержащий текст или данные.
- **Фрейм** — отдельное окно программы.
- **Окно** — область внутри фрейма, отображающая буфер.
- **Минибуфер** — строка ввода команд.
- **Точка вставки** — текущая позиция курсора.

### Преимущества Emacs
1. Высокая расширяемость.
2. Большое количество режимов.
3. Работа в терминале и графическом интерфейсе.
4. Эффективное управление клавиатурой.
5. Интеграция со средствами разработки.

## Основные команды
### Работа с файлами
- C-x C-f — открыть файл
- C-x C-s — сохранить файл
- C-x C-w — сохранить как
- C-x C-c — выход

### Перемещение
- C-p, C-n, C-f, C-b
- C-a, C-e
- M-<, M->

### Редактирование
- C-k — удалить до конца строки
- C-space — начать выделение
- C-w — вырезать
- M-w — копировать
- C-y — вставить
- C-/ — отмена действия

## Работа с окнами и буферами
- C-x C-b — список буферов
- C-x b — переключение буфера
- C-x 2 — разделить окно горизонтально
- C-x 3 — разделить окно вертикально
- C-x 0 — закрыть текущее окно
- C-x 1 — оставить одно окно

## Поиск и замена
- C-s — поиск вперёд
- C-r — поиск назад
- M-% — поиск и замена с подтверждением
- M-s o — альтернативный режим поиска

6. Разделение окна на несколько частей.
7. Работа с несколькими буферами.

## Контрольные вопросы
1. Emacs — многофункциональный редактор с поддержкой расширений.
2. Сложность для новичков связана с большим количеством сочетаний клавиш.
3. Буфер хранит данные, окно отображает буфер.
4. Можно открыть десятки и сотни буферов.
5. При запуске создаются служебные и рабочие буферы.
6. Комбинации вводятся последовательно с использованием Ctrl и Meta.
7. Окно делится командами C-x 2 и C-x 3.
8. Настройки обычно хранятся в `.emacs` или `init.el`.
9. Клавиша Meta используется как префикс.
10. Emacs удобен гибкостью и расширяемостью.
